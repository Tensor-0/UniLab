# DM10 结构与实测质量

> 2026-09-20。这个目录放 DM10 的结构图，以及**实测质量**与**仿真模型**的对照。
>
> 起因：仿真模型整机 **10.86 kg**，实机（含板子/IMU/线缆）**约 6 kg**。
> 逐段核对后发现**不是统一偏重，而是每段错得都不一样**（0.87× ~ 3.86×）。

## 结构（13 body / 11 joint / 10 actuator）

```
world
└─ base_link                     [free 关节]
   └─ loin_yaw_Link              ⚠️ 无关节（焊死的腰）
      ├─ leg_l1_link  ⟳Y  髋P
      │  └─ leg_l2_link  ⟳X  髋R
      │     └─ leg_l3_link  ⟳Z  髋Y
      │        └─ leg_l4_link  ⟳Y  膝
      │           └─ leg_l5_link  ⟳Y  踝
      └─ leg_r1..r5_link          （右腿，完全对称）
```

**关节轴直接从 `jnt_axis` 读出**，与"髋P/髋R/髋Y/膝/踝"的命名一一对应。

## ⭐ 10 个电机的分布（核对过，总数对得上）

| 装在哪个 body | 个数 | 说明 |
|---|---|---|
| `loin_yaw_Link` | **2** | 腰，两条腿共用 |
| `leg_l1_link` | 1 | ×2 条腿 |
| `leg_l2_link` | **0** | ← 这一段不装电机 |
| `leg_l3_link` | **2** | ← 这一段装两个 |
| `leg_l4_link` | 1 | ×2 条腿 |
| `leg_l5_link` | **0** | ← 这一段不装电机 |
| **合计** | **10** | 2 + (1+0+2+1+0)×2 = 10 ✅ |

单只电机 **362 g**（DM-J4340-2EC 说明书标称）。

## 怎么改的

见 `dm10_measured.xml`（**另存，未覆盖 `dm10.xml`**）：

```python
mass_new        = 实测值
diaginertia_new = diaginertia_old × (mass_new / mass_old)
```

**⚠️ 惯量按比例缩放是个假设** —— 前提是"形状估得对、只有密度错"。
但原始质量填得如此随意（0.87×~3.86×），**形状估计也未必准**。
⇒ 这版够用来训站立/走路，**不适合做精细动力学分析**；要更准得用 CAD 算或做摆锤实验。

## ⚠️ 换了质量，PD 增益就不对了

现有 `kp = 30.15` 是配 **10.86 kg 模型**调的。新模型轻 44%，
**同样的 kp 在轻机器人上会欠阻尼（过硬、易振）**。

`HANDOFF-dm10-actuator.md` 里"真机 kp 16-20 对 MuJoCo 太软"那条结论，
**是在旧模型上得出的，需要重做**。
